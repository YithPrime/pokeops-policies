Privacy Policy

Effective October 23, 2026

Nightfall is an unofficial, community-operated Discord bot for Vampire: The Masquerade V5. This policy describes the current local Windows implementation operated by the maintainer of YithPrime. Its features include dice rolls, saved fictional character profiles, character dialogue, and Prague chronicle announcements.

Information received and processed

Nightfall processes Discord user, server, channel, and message identifiers; command options; gameplay labels and dice results; and the permissions needed to perform requested actions. Character features process the fictional names, portrait images, attachment metadata, and selected speakers that players provide.

When Message Content Intent is enabled, Discord can deliver ordinary message content, attachments, and related message metadata from channels the bot can access. Nightfall checks whether the author has selected an owned character in that exact channel or thread. It converts eligible messages only for that selection. Bots, webhooks, direct messages, and messages beginning with // are not converted. Messages without an active selected speaker are left unchanged.

For an eligible character post, the bot temporarily processes the text, formatting, attachments, reply reference, and edit information needed to deliver the copy and check the source before removal. It does not download channel history or build a local archive of conversations.

What is saved

A SQLite database on the operator's computer stores character names, portrait bytes and media types, Discord portrait attachment URLs, source portrait message/channel IDs, owning Discord user/server IDs, and each player's selected character per channel. It also stores administrator-configured reset channel IDs, the Prague local schedule, enabled state, the last delivered reset date, and the administrator-authored reset title, opening text, closing notes, and revision number.

Dialogue text, ordinary attachments, and roll results are not saved as a local history by this implementation. Roll controls temporarily hold the player's ID and dice in memory for up to fifteen minutes. A bounded set of recently handled message IDs is held in memory to avoid duplicate processing and clears when the bot restarts. Message and attachment data used for delivery is processed temporarily. The Discord client can also cache recent received messages and metadata in memory while the bot runs; this includes messages that are not converted. This cache is not a saved conversation history and clears when the process stops. Operational logs may record startup events and error types; the bot is not configured to log conversation text.

Purpose and visibility

Information is used to execute game commands, show and manage owned character profiles, deliver character dialogue, enforce player and server permissions, and schedule announcements. Nightfall does not sell personal data, serve advertising, profile players for marketing, or send message content to AI services or use it to train AI models.

Character dialogue is posted through a Discord webhook with the selected fictional name and portrait. After complete successful delivery, Nightfall attempts to remove the player's original message. Long posts may become several messages. Reuploaded portraits, dialogue, attachments, and dice output are visible to people with access to their Discord channel. A failed delivery can leave the original or partial copies in place.

Discord and other service providers

Discord receives and stores commands, messages, portraits, and attachments under Discord's Privacy Policy. Character portraits are published in a persistent Discord profile message, and their attachment URL is used for the circular avatar. Deleting that profile message can break the avatar.

For announcements, Nightfall requests weather and solar information from Open-Meteo and lunar information from the US Naval Observatory. Requests use the configured fixed Prague coordinates and date/time information, not players' locations. These requests do not include Discord user IDs, dialogue, character portraits, or ordinary attachments. Like other network services, the providers can receive the requesting computer's IP address and routine connection information.

These public policy pages are hosted with GitHub Pages, and support requests use GitHub. GitHub handles website visits and support submissions under its privacy statement. These pages add no analytics scripts, advertising, or account system. Information may also need to be disclosed where required by law.

Retention, control, and deletion

Saved profiles and selections remain while needed for the selected features, until removed by the player or operator. /char off clears your active selection in the current channel. Renaming a character updates its saved selections; removing a character with /char remove removes that character and its selections.

Use /privacy_erase confirm:DELETE to remove all of your saved Nightfall character profiles, local portrait bytes, and associated speaker selections across servers in this bot's database. This command requires the running bot to be available. It does not remove shared server reset settings or announcement wording. These records contain no configuring user's ID, but administrator-authored wording may include information the administrator enters. Administrators can replace the wording with /reset edit, stop reset announcements with /reset disable, and ask the operator to remove the stored configuration.

Removing the bot from a server while it is connected purges that server's saved profiles, selections, and reset configuration. If removal happens while the bot is offline, ask the operator to complete that cleanup. The operator will also remove data when it is no longer needed or when operation ends, and will address applicable access, correction, and deletion requests through the contact route below.

Local deletion does not remove earlier Discord messages, webhook copies, portrait profile messages, attachments, or data retained by Discord. Ask the bot operator or server moderators for help removing those Discord posts. The implementation does not create off-device backups; any independently maintained copies must be considered separately when fulfilling a deletion request.

Security and eligible users

The operator controls access to the local computer, database, and bot credentials. No service can guarantee absolute security. Use fictional character information, upload only images you have permission to use, and do not submit credentials, identity documents, financial or health information, or other sensitive personal information.

Nightfall is intended for people eligible to use Discord under Discord's terms and applicable minimum-age rules. It is not designed to collect information from people below that minimum age.

Changes and contact

This policy will be updated when the implementation or its data handling changes. The effective date above identifies the current policy.

For Nightfall support, privacy questions, reports of misuse, or access, correction, or deletion assistance, contact the operator through the public support page, identifying Nightfall in the title, or through the Discord server where you use the bot. GitHub issues are public. Do not post tokens, private conversations, portraits, or other sensitive information there. For a private matter, initially request a private follow-up without disclosing the information.
